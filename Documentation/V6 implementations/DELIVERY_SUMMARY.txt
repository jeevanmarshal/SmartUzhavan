💡 PRO TIPS FOR SUCCESS

1. Use Postman for all backend testing
   → Test each endpoint before connecting frontend
   → Save collection for future testing

2. Keep browser DevTools open
   → Watch Network tab for API calls
   → Monitor Console for errors
   → Check LocalStorage for auth token

3. Commit changes frequently
   → After each working feature: git commit
   → Easy to rollback if needed
   → Clear history of progress

4. Test each feature fully before moving on
   → Test happy path (success case)
   → Test error path (validation, 404, etc.)
   → Test edge cases
   → Verify no console errors

5. Document as you go
   → Update README with changes
   → Record what you learned
   → Help future team members

🆘 EMERGENCY PROCEDURES

If Something Breaks:
  1. STOP immediately
  2. Identify what broke
  3. Revert from backup
  4. Understand what went wrong
  5. Request different approach from agent
  6. Resume when you understand the issue

If Agent Makes Unauthorized Changes:
  1. STOP agent immediately
  2. Revert all changes
  3. Review AGENT_GUARDRAILS.md
  4. Give clearer instructions
  5. Resume with stricter oversight

If Frontend Breaks:
  1. Check git history
  2. Identify the breaking change
  3. Revert that specific change
  4. Test to verify it's fixed
  5. Request different approach

If PDF Server Breaks:
  1. Revert /server folder from backup
  2. Verify PDF server works again
  3. Investigate what happened
  4. Add to "DO NOT TOUCH" list
  5. Continue implementation
